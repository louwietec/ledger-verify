# sprachregel_verbote.txt, Version 1.1.0
#
# Versionierte Verbotsmusterliste der Sprachregel (siehe
# registry.json -> language_rule.forbidden_patterns_file).
# Verbindliche Formulierung stattdessen: "unterstützt die Erfüllung" /
# "supports fulfilment"; nie eine Erfüllungs- oder Konformitäts-Behauptung.
#
# Format: eine Regex je Zeile (Python-re-Syntax), Kommentarzeilen beginnen
# mit '#', Leerzeilen werden ignoriert. Die CI (.ci/check_sprachregel.py)
# prüft EXAKT diese 24 Muster, case-insensitiv, über spec/, appliance/web/
# und appliance/internal/i18n/. Ausnahmen: Zeilen mit dem Marker
# sprachregel-allow (Doku-Zitate) sowie diese Datei selbst.
#
